Ключевое: Иегуда работает в Израиле с марта по октябрь 2027, только онлайн, под
именем יהודה כורשן, сайт на иврите, платной рекламы нет, оплата Bit/PayBox/карта/PayPal,
квитанции автоматом, у него уже есть статус עוסק פטור. Основа сайта — Lt + CF7 как
на tutor.

Писать «הומאופתיה» без «й»: вариант с «й» в Google практически не ищут (research/02).
Уведомлять Управление по защите частной жизни нужно только при базе более 100 000 человек.

**Why:** в Израиле гомеопатия не лицензируется, поэтому юридический риск в
формулировках и в данных клиентов, а не в праве практиковать.

**How to apply:** любой текст для сайта — без «лечения болезней» и слова «врач»,
с пометкой «требует вычитки носителем». Данные клиентов в России не собирать, пока
юрист не подтвердил схему. Связано: [[tutor-homeoclass-ru-site]] (в соседнем
репозитории curshen_info).

Настройки Lt: `plugins/setup/lt-config.php` (сроки 7 дней, редиректы, письма на иврите; страница «הארכת גישה», слаг `renew`, пока пустая). Опросник: форма CF7 28 «שאלון ראשוни כללי», страница `/general-primary/` (29), файлы в `plugins/forms/`, создание — `plugins/setup/forms-setup.php`. 11 вопросов, письмо врачу от ask@homeoclass.co.il. ## Почта сайта и подписки (31.10.2026)
Письма с сайта идут через WP Mail SMTP (бесплатный) в режиме Gmail API, отправитель altevacure@gmail.com. Причина: у IP 31.42.188.5 нет PTR, и Gmail отклоняет письма с сервера Shneider (550-5.7.25); обращение в поддержку о PTR написано, ответа нет. Google Cloud: проект `altevacure` (authuser=3), клиент OAuth «homeoclass» с redirect `https://connect.wpmailsmtp.com/google/`, приложение опубликовано (In production), иначе токен живёт 7 дней. Для Cloud потребовалась двухэтапная проверка в аккаунте. Секреты хранятся только в настройках плагина.

Comment Mail Pro скопирован с tutor (без .git), настроен `plugins/setup/comment-mail-config.php`: тип записи discursion, письма на иврите, ответы по почте через Make выключены. mu-плагин `hco-admin-subscribe.php` подписывает на каждую новую консультацию только пользователей с ролью homeopath (сейчас curshen@homeoclass.co.il, он пересылается на Gmail; yehuda не подписан, чтобы не было дубля). Проверено: клиент и два администратора подписаны, очередь отправила уведомления. Пользователь `curshen@homeoclass.co.il` создан с ролями administrator и homeopath, пароль в `.hco-admin-credentials` на сервере.

Вход и выход (31.10.2026): плагин Login Logout Menu 1.5.2, как на tutor. В меню Main один пункт с адресом `#loginpress-loginlogout#` и названием «כניסה לאזור האישי | יציאה מהאזור האישי»: гость видит левую часть, вошедший правую. Название «אזור אישי» выбрано по употреблению на порталах государства и банков, «מרחב אישי» встречается реже. Мой первый вариант (mu-плагин с подменой адреса по роли) убран. Вход клиентов в админку закрыт mu-плагином `lt-admin-lock.php`: проверено временным клиентом, `/wp-admin/` и `profile.php` отправляют его на главную. `admin-ajax.php` открыт.

Панель срока доступа (31.10.2026): Lt сам кладёт в верхнюю панель WordPress строку «Ваш доступ активен еще» с шорткодом `[tminus]` (нужен плагин jquery-t-countdown-widget), текст зашит по-русски в `src/ShortCode.php`. Правки Lt затираются обновлением, поэтому mu-плагин `hco-access-bar.php` убирает узел `my_page` и ставит свой на иврите: недели, дни и часы без секунд, считается на сервере. Администраторам не показывается; клиентам без `paidto` (нет оплаченного срока) тоже. Защита не от панели, а от Lt и lt-admin-lock.

## Ответы по почте через Make (31.10.2026)
Схема как на tutor ([[rve-makecom-reply-by-email]]), но собрана самим плагином: `RveMakecom::setupWebhook()` создал в Make почтовый хук 4479224 «Comment Mail Pro - homeoclass.co.il - Mailhook» и сценарий 10078296 «Comment Mail - homeoclass.co.il» (Custom mailhook → HTTP POST на сайт с ключом). Токен, команда и зона Make скопированы из настроек tutor на самом сервере (тот же аккаунт Make), в репозиторий и в чат не попадали. Хук надо создавать заранее с точным именем: если такого нет, плагин берёт «первый попавшийся» mailhook, то есть чужой. Скрипты: `plugins/setup/rve-makecom-setup.php`, `rve-makecom-check.php`.

mu-плагины: `rve-registration-fix` (комментарии для гостей закрыты, `comment_registration=1`, мимо только запросы с верным ключом), `fix-rve-user-id` (автор определяется по ключу подписки из письма, потом по адресу отправителя; поэтому ответ врача с Gmail или Mailbird записывается от имени curshen@homeoclass.co.il), `disable-rve-flood-check`, `lt-rve-guard` (письма на иврите, страница продления `renew`), `rve-strip-quote-tail` (правила для русских цитат, под иврит не проверялся), `he-strings` (английские фразы писем Comment Mail переведены).

Проверено: клиент → письмо врачу на curshen@ → ответ из Mailbird → комментарий от пользователя 4 без цитаты. Ответ от врача к клиенту уходит на altevacure+hco1@gmail.com. Без цитаты исходного письма ответ молча теряется (маркер `~rve#` в теле).

SEO-плагина на сайте нет, meta description не заданы.
По решению Иегуды 01.11.2026 в каждой статье один абзац перед блоком «מתי לפנות לרופא קודם» называет запросы «תרופה הומאופתית ל…» и «טיפול הומאופתי ל…» и объясняет, почему я говорю «רמדי». Больше нигде «תרופה» и «טיפול» о гомеопатии не употреблять.
